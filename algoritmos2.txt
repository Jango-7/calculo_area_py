Problematica:

El user quiere saber cual es el area de un circulo, teniendo el radio.
-------------------------

Algoritmo:
1. Solicitar al user que ingrese el radio del circulo.
2. Calcular el area del circulo, usando la formula: area = π * radio^2
3. Mostrar al usuario el área calculada.

-------------------------------

Pseudocodigo:

inicio
    # Paso 1: Solicitar al user que ingrese el radio del circulo.
    Mostrar mensaje: "Por favor, ingrese el radio del circulo."
    Leer el dato ingresado, y asignarlo a la variable radio con tipo flotante.

    # Paso 2: Calcular el area del circulo, usando la formula: area = π * radio^2
    Definir y asignar a la variable area el resultado de π * radio^2

    # Paso 3: Mostrar al usuario el area calculada
    Mostrar mensaje: f"El area del circulo con radio {radio} es {area}"
